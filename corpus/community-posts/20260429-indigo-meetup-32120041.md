上周末我们在 Bellevue 办了一场小范围的晚宴沙龙，请到了 Indigo（芦义 / Jedi Lu）来做关于 Agent 时代的投资、创业、组织变化的分享，加上 Master Sommelier Nick Davis 带的 Pacific Northwest 红酒品鉴。

整个晚上从下午 4 点一直聊到 9 点。前两个小时是 Indigo 的主题分享和现场 Q&A，后面边喝边聊到深夜。

Indigo 这个分享自己也定义为"比较杂"——他把过去半年在直播、Podcast、文章里讲过的东西，加上最近两周刷新出来的新看法，揉在一起讲了一遍。他原话是："时代变化太快，每两周就要 Refresh 一下。Anthropic 上线的时候每天一个版本，干完之后刚刚好。"

这篇 Notes 我会按 Indigo 实际讲的脉络来整理，尽量保留他的表达方式和判断的 sharpness。文章比较长，但我觉得里面很多观点值得反复读。

## 一、先讲 Taste：为什么这是 AI 时代最重要的能力

Indigo 把 Taste 放在了所有投资和创业方法论的最前面讲。

他的核心论断是：**AI 是放大器，不是均衡器。**

> "在过去用软件的时代，软件交互结果确定。你用 Word 输出文档、PPT 做东西，结果都是稳定的。但 AI 时代，你的提示词、流程、选择的结果不一样，差别会非常大。所以 AI 不是让所有人能力接近，而是让人和人的差异变得更大。"

他引用了 Paul Graham 的两篇 Taste 评论——一篇 2002 年写的，一篇最近写的，时隔 20 年。Paul Graham 想说的是：**Taste 不是玄学，不是个人偏好。**

> "如果品味只是个人偏好，那'更好'就不存在了。"

Indigo 把 Taste 的可工程化拆成了几个维度：

- **本质**：好的东西永远在解决正确的问题。很多创业第一步问题就问错了，那这件事本质上就错了。
- **特征**：有启发性、有幽默感、奇特、物理上对称——一个看起来很美的飞机飞起来一定漂亮，一个漂亮的数学公式很可能是对的。
- **过程**：看上去容易，执行起来艰苦。优雅的设计永远是迭代出来的，不是一次成型。SpaceX 的引擎 V1 V2 V3、Tesla 的车、苹果的产品都是。
- **生态**：天才总是扎堆出现的。15 世纪的佛罗伦萨、19 世纪末的巴黎、现在的湾区，这种"高浓度人才在网络催化下涌现"的节点效应是真实存在的。

最后他特别强调了一个点，叫做**"唯一的风格就是别无选择"**。

他用李佳琦举例（他是李佳琦背后的美 ONE 公司的早期合伙人之一）。李佳琦最开始什么都试过——卖衣服、卖食品、什么都做。最后发现只有美妆能做出来，就只做美妆。他每天直播十几个小时，一开始没流量，磨了半年。但当他把所有"迎合"的部分都剥掉，把自己最纯粹的那一面（一个特别会涂口红的男生）做到极致，这件事就成了。

> "人活到最后、产品做到最后、公司走到最后，都做成最像自己的样子。但他肯定不会活成别人讨厌的样子。"

这句话他当晚说了两次。

## 二、思考框架：用三层结构区分信号与噪音

Indigo 给自己设计的核心思考框架，是把所有发生的事情按三层归类：

**第一层：事件层。** 政策变化、新闻、推文、贸易战、公司财报、CEO 言论。这一层 95% 都是噪音，但变化最频繁。特朗普每天发的推可以拿来炒短线股票，但绝不能当成结构性判断的依据。

**第二层：结构层 / 制度层。** 变化缓慢但深远。比如 ChatGPT 的发布、电商的诞生、智能手机的普及。Indigo 认为 OpenAI 不是昙花一现，因为它在 AI 这个里程碑上产生了一个结构性变化；但前段时间各种"用 GPT 做的社交网络"那种就是事件层的噪音。

**第三层：解释层。** 最底层、最缓慢，但一旦发生影响最大。比如爱因斯坦相对论、量子力学、标准模型——这些是改变人类对世界基本理解的进步。AI for Science 如果真能在生物、物理、材料上推动基础科学进步，那就进入了解释层。

Indigo 自己已经把这套分类做成了知识库里的判定逻辑：每天看到一条新闻，让自己的 Agent 在 Claude Code 里先帮他归类——这个属于事件层、结构层还是解释层？

> "他可能看得比我还清楚。"

**这个框架的实际用途**是：当你在二级市场配置主题、在一级市场判断创业方向、甚至在做内容选题的时候，先问"这是哪一层"。事件层的东西可以快进快出，结构层的东西可以重仓长期持有，解释层的东西甚至可以改变人生方向。

我们正在经历的，是结构层和解释层同时松动的时代——按 Indigo 的说法，这种时代窗口可能 30 年才有一次。

## 三、投资框架：Rewired Index 五层结构

这是 Indigo 自己设计的投资分析框架，他在去年底画出来的，结果今年 GTC 上黄仁勋讲了一个非常类似的五层架构。

从下到上五层：

1. **能源 / 物理基础层**：电力、发电、能源公司。
2. **算力 / 数字基础设施层**：芯片（NVIDIA、TPU、AMD）、Neo Cloud、数据中心、海底光缆、存储、光通信。
3. **全栈公司层**：模型公司 + 拥有完整生态的巨头，比如 Google、Meta、Tesla、xAI。
4. **原生 AI 应用层**：自动驾驶、企业 AI、AI Agent 应用。
5. **前沿探索层**：太空、量子、AI for Science、生物、材料、国防。

他强调这个框架最大的价值不是给散户用——是为了让自己的 Agent 能更好地干活。

> "我把这个架构告诉它之后，AI 可以很快地把任何一家公司给分解开来。"

举例：让 Claude 把 Google 拆解一遍。Google 的核心是 Search + 广告（应用层）→ Gemini（模型层）→ TPU + 海底光缆（物理层）→ Search/Maps/YouTube/Android 的数据（数字基础层）→ Waymo、Workspace、DeepMind 的 Isomorphic（前沿）。每一层是核心、压舱石、增长引擎、还是主题机会，一目了然。

**主题（Theme）vs 压舱石（Core Holding）的区别**很关键：

- 主题：信号一出来加仓，信号一过卖掉。比如最近的"光通信替换数据中心同轴电缆"，这就是个主题。
- 压舱石：长期持有，跟随结构性变化享受复利。

Indigo 的判断是 2026 年的一二级市场依然是 **AI + 硬件**驱动。他们最近两期基金加上一些 SPV 投了 9 家"The Seller 30"榜单上的公司——SpaceX、Anthropic、Crusoe（绿色能源数据中心）、Anduril 系（国防自动化）等等。

特别提到 **国防** 是除了机器人和 AI Harness 之外，**最快能变现的方向**——比机器人快得多。

> "现在美国的仗打得莫名其妙，但是把全世界的国防问题都暴露出来了。武器不够，无人机搞不定。这是很好的一次机会。"

## 四、五年内的核心结构性变化：软件 + 人力 → 模型 + 算力

这是整晚 Indigo 反复强调的核心判断：

> "软件加人力，会变成模型加算力。"

他在 PPT 上画了一个对比图。意思是：过去这一万亿美金的软件市场和八十万亿美金的劳动力市场，本质都会被 AI 重构。

**短期（5 年内）的变化主要发生在数字世界。** 软件公司被通杀——不是说现在财报不好，而是市场已经在 price in 它两年后无法增长。微软、SaaS 龙头、各种数字工具，估值都在被压缩。Indigo 觉得很多公司是错杀，但没办法，市场就这样走。

**长期（5 年之后）的变化在物理世界。** 机器人、太空、AI for Science、量子计算、生物材料——这些 2030 之后才会真正成熟。

> "我现在做基金，肯定要投这些。就像我 2022、2023 年在投模型一样——你肯定要往前看。"

值得注意的是他对**人力**的判断：

> "人力不是消失了，是人力资源的分配变了。很多工种会变。"

这个观点比单纯说"AI 取代人"要冷静、要准确得多。

## 五、软件正在被重写：面向文件编程 → 面向 Agent 编程

这是一个非常实操的判断。Indigo 自己已经在这么干了。

过去 10 年我们写软件是"面向文件编程"——我编辑这一行代码、那一个 GUI 控件。现在我们对着 Claude Code、对着 Cursor，选中一个文件夹说"把这个改成那样"，它就交付出来了。

更进一步：**Agent 之间的交互不再需要 UI，只需要 Markdown / JSON 中间文件。**

Indigo 自己现在所有的工作目录是这样组织的：

- 每个文件夹是一个 Agent 的工作空间
- 交互文件是 Markdown
- 当需要给人看的时候，把 Markdown 渲染成网页或文档
- 不需要给人看的时候，Agent 之间直接读写 JSON / Markdown 互相协作

**结论：UI 这一层会越来越萎缩。**

这意味着大部分纯做"逻辑层 + UI 层"的 SaaS 会被杀死。后面 Q&A 里有人提到这个判断，Indigo 进一步澄清：

> "杀死的意思是说，现在纯粹只提供逻辑层和 UI 层的这些 SaaS 会被杀死。Inference SaaS（带核心推理价值的 SaaS）不一定会死。"

## 六、Harness 是 2026 最大的创业机会

Indigo 反复讲这个概念。

Harness 直译是"马具"——你有一匹好马（最强的模型），但还需要一套好马具（缰绳、马蹄铁、马鞍）才能驾驭它。

**为什么 Harness 是结构性机会？**

模型公司自己做的合作工具是高度泛化的，做不了行业纵深。但企业实际部署 AI 的时候，需要大量行业 Know-How、上下文管理、合规、私有化部署、定制化集成——这些都是 Harness。

**机会在两端：**

1. **小型 Cloud / Inference 服务商**（Together AI、Fireworks、Modal 这一类）：传统大厂（AWS / GCP / Azure）转型很慢，反而是这些为 Agent 时代而生的轻便云厂商有机会快速切入。
2. **专注垂直行业的 Harness 创业公司**：开源 + 行业沙盘 + 私有部署。Indigo 的判断是这类公司应该先做媒体（在 GitHub 打榜、在 X 上 Build in Public），再做社区，最后再做产品。

**关于"做泛化还是做垂直"，他的判断很清晰：**

> "于创业来讲，都不应该去做 General。General 这件事让模型公司去做。要么开源做社区生意，要么深耕一个行业把它做透——那些通用 SaaS 全部为这个行业的客户提供。"

他举了课代表（也就是 Superlinear Academy）做的事情作为例子——做企业培训也是这个逻辑：你深入到一个企业里面去帮他们落地 Context Architecture，这是模型公司不会做的事情，但价值密度极高。

## 七、IT 家政：新雇佣关系正在形成

这是当晚一个让全场笑出来但其实非常严肃的观察。

Indigo 的判断是：**很多中小企业其实买不起也用不动 SaaS。** 他们既请不起全职的 AI 工程师，也不可能等 SaaS 厂商来定制化。

> "他们需要 IT 家政。"
> "你请保洁阿姨，是钟点工模式，她可以同时服务 3-5 家企业。未来好的 AI 工程师也是这样——一个人服务 5 家公司，私有化部署、AI 集群定制、极速开发交付。"

为什么这件事会发生？

- 大厂在裁员，好的工程师在外溢
- 小公司给不起大厂的工资
- 但小公司又特别需要 AI 改造
- 工程师拿到几个客户，单个客户付的钱不比大厂多，但多个客户加起来收入比之前高

**这背后其实是一种新的劳动力市场结构。** Indigo 提到社区里有个人之前在做 Over Employment（同时打 4 份工），结果这一年被裁掉 3 份只剩 1 份。后来他开始接政府的合同——通过信息差和能力差，去帮政府做一些 AI 系统改造，单子规模反而比打工大。

**这件事正在发生，而且会衍生出新的平台机会**——撮合工程师和需要 AI 改造的中小企业的 marketplace，类似 Toptal 但更轻、更 AI-native。

## 八、组织正在被重构：中层管理的消亡

这是当晚另一个重磅判断，Indigo 用了 Jack Dorsey 之前发的一篇文章作为参考。

**当前组织的本质是"罗马军团"：层级化的信息传递机制。**

中层存在的唯一意义是 **信息传递**——上传下达、对齐、分配任务、汇报进度。但这正是 AI 最擅长的事情。

> "现在所有行业的中间层都很难。中产被挤压、企业的中间层被挤压。"

Indigo 在他自己的直播公司做过 AI 实施，发现中层"上面骗老板、下面骗员工"——而下面有很多很聪明的员工把 AI 用得很好，但因为组织结构限制，**有十倍速员工但没有十倍速组织**。

**未来的组织形态：**

> "可能以后就 CEO 或老板了，不需要 VP 了。每个部门 VP 都是最好的模型——买最好的模型，给它最多的 Context，让它直接给底层的执行员工安排任务。"

- 中心：AI 模型 + 调度系统
- 边缘：人类员工，做的是"人才能做的事"——触达真实世界、提供温度、文化判断、伦理判断、销售关系、情绪价值

> "AI 再牛 X，道德伦理判断也没人好。因为人有心智模型（Theory of Mind），AI 没有心智模型。我们人看同类是有心智模型的。"

人类员工要从层级金字塔的中间，**移动到组织的边缘**——这里的"边缘"不是贬义，是说人去做接触真实世界、接触客户、做不了自动化的那一端。

Indigo 提到湾区已经有公司这么做了。一家原来 150 人的公司，把所有写代码的程序员全部开掉，只留下"Conductor"（指挥 Agent 的人），现在大概 30-50 人规模。中层全部消失。

**他的核心结论：**

> "公司会变得非常社群化。Community 没有层级，Community 有共识。这两个东西很重要。"

## 九、两种 World Model：公司模型 与 客户模型

Indigo 把企业的 AI 应用场景高度抽象成两种：

**公司世界模型（Company World Model）：** 帮企业管理自己内部——流程、文档、知识、决策，把内部 Context 流水做清楚。

**客户世界模型（Customer World Model）：** 帮企业理解和服务客户——CRM、个性化、行为预测、客户旅程。

> "这就这两件事情。这两件事情中间都有 AI 模型的概念。"

**结论：**

- 纯逻辑层 + UI 层的 CRM 软件会被杀死——因为 Agent 可以直接驱动数据库
- 但 Salesforce 这类有客户关系、有大企业入口的公司不一定会死——他们可以转型成"帮企业建立 Customer World Model"的服务商
- HubSpot 这种偏中小企业、偏自动化的，反而最危险

如果你在做 to B 创业，问自己：**我的产品属于哪一边？是帮别人做公司模型，还是帮别人做客户模型？**

## 十、哑铃结构：精品端 vs 量大管饱端

Indigo 引用了一篇叫《10x Lawyer》的论文，但说"这个图放在任何行业都成立"。

行业被 AI 改造之后会形成一个哑铃：

**左端（精品 / Boutique 端）：**

- 顶尖 Taste + AI 加持
- 单价极高、量极少
- 替代传统大律所、大咨询、大 4A 的精英层

**右端（量大管饱 / AI Vendor 端）：**

- 极低成本、AI 全自动化交付
- 单价极低、量极大
- 服务过去用不起这些服务的中小客户

**中间（Death Valley）：**

- 既没有顶级 Taste，又没有极致成本
- 只能靠人力堆量、组织庇护赚信息差
- 最先被淘汰

**核心判断：**

> "客户的转变发生在每一次无声的成功交付。当 CFO 发现新的 AI Vendor 比传统 4A 便宜 5 倍、做得还更快——只需要两三次签单，信任就转移过去了。"

任何行业（律师、咨询、设计、内容、教育）都会经历这个哑铃化。**选择在哪一端做自己的生意——这是 2026 年所有创业者必须想清楚的事。**

## 十一、Building 的新顺序：先做媒体，再做社群，最后做产品

这是 Indigo 给现场所有创业者的一个非常具体的建议。

他的论据：写代码这件事的边际成本已经趋近于零。Cursor、Claude Code 让任何人都能日产几千行代码。**当代码可以量产，代码本身就不那么值钱了——值钱的是 Attention。**

**正确的 Building 顺序：**

1. **先做媒体。** 在 X、YouTube、Newsletter、播客、公众号上持续发声，建立你这个领域的声誉节点。
2. **再做社群。** 围绕你的内容把同频的人聚集起来——Discord、Circle、微信群、Slack。
3. **最后做产品。** 在媒体和社群的双重杠杆下，工具的冷启动会快得多。

他举了 [Every.to](http://every.to/) 作为典范——本来是个 Newsletter，现在是产品公司、有课程、有社区、还做考察团。"和你（指我们 Superlinear Academy）做的事情很像。"

**Indigo 总结的创业心法：**

- **坦率有威力。** 这是某篇论文的标题，他特别喜欢。Building in Public、Default to Public、Everything is Media——这些都是同一个意思。
- **拥抱一次性软件。** 不要执着于做"永久性的、长青的"软件。

"我今天做这个工具解决今天的问题，下个月市场变了我做下一个工具。只要我的设计师在、媒体在、社群在，用户就会接受我们换产品。"

他举了 P 调频 Pieter Levels 的例子——那个人已经 build 了 42 个项目，平均每个用几周就上线。
- **不要做泛化。** 要么深耕一个垂直、要么开源做生态、要么走精品路线、要么走极致低成本路线。中间地带是死亡之谷。

## 十二、一些更长远的判断：娱乐、太空、国防、AI for Science

**关于娱乐——这是当晚很重要的一个判断，但带着一点黑色幽默。**

> "如果说 UBI 真的来了，机器人 7-8 年后真的能干很多活了，人就只能去娱乐。所以娱乐行业是未来唯一的行业。"

Indigo 的观点：现在投 to C 的 AI 应用风险非常高——因为整个产业链在 to B 端先释放价值（让企业先提效率、先裁员）。to C 端真正成熟要等到：

- 苹果在 2027 年发布 Apple Glass
- 苹果在 2028 年发布下一代 Vision Pro
- World Model / 空间智能 / AIGC 短剧再迭代两三代

> "C 端 AI 真正爆发要 2029-2030。Vision Pro 做早了 10 年。"

**但他对未来 2 年人类社会的走向其实是悲观的：**

> "我对人在两年之后的走向会很悲观。如果有机会娱乐，赶快娱乐吧。"

他援引第一次工业革命之后产生了 50 年暴力——被工业革命取代的农民找不到工作整整 50 年，才有新的工作出现。AI 革命可能也会有这样的过渡期。"青年失业率"、"找不到工作的大学生"是结构性变化的早期信号。

**国防 + 太空 + AI for Science** 是他一二级市场都重仓的方向。这些是物理世界 + 解释层的变化，是 5 年之后的下一波。

## 现场 Q&A 精华

**Q1：SaaS 真的会死吗？**

A：要分两类——

- Application SaaS（纯逻辑层 + UI 层）：会被杀死。因为 Agent 可以直接驱动数据库。
- Inference SaaS（核心是推理价值的 SaaS，比如 Tempura 这类）：不会死。它本质提供的不是 UI，是知识和判断。

**Q2：基础设施层（光、存储、TPU vs GPU）怎么看？**

A：

- **光通信**最近最火，但已经有泡沫，机会更多在主题轮动。
- **存储**确定性最高——模型推理的 Context 越来越大、KV Cache 越来越大、视频生成会爆炸式增加存储需求。这块的长期增长非常确定。
- **TPU vs GPU**：不是你死我活的关系。TPU 在专项推理上效率高，但 GPU 灵活性强。一旦模型架构有变化，GPU 的优势就出来。两边都会涨。
- **Apple Siri 的 AI 调度架构**：如果苹果在 2026 WWDC 真的把这个做出来，整个生态的算力消耗会再上一个台阶。

**Q3：娱乐真的会爆发吗？**

A：现在 OpenAI 已经因为 Sora 太烧钱把服务停了——根本用不起。**算力还远远没到能让娱乐爆发的程度。** 但等模型成熟、硬件（XR / AR）成熟、+ 苹果 2027-2028 的产品周期到位，娱乐会成为下一波超级赛道。"如果说娱乐成熟要到 2029-2030，那现在投 to C 的 AI 太早了。"
