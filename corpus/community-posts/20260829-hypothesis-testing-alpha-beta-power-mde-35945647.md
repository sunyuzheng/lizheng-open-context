假设检验可能是数据科学里最基础、最普遍，也最容易被误解的概念之一。

我做过500多期数据科学视频，但这期是第一期我会说“所有数据科学家都应该看”的内容。不是因为假设检验有多冷门，恰恰相反：我们每天都在使用它，却经常只能背出定义。谈到α、β、power、MDE，很多人还得回去翻教科书；一旦追问这些概念为什么这样定义、彼此怎样连接，理解就开始松动。

问题不只是公式难。更大的原因是，很多现代教材和网上文章没有明确告诉你，它们在Fisher的显著性检验与Neyman–Pearson的假设检验之间切换。两套框架都合理，现代实践也经常把它们结合使用；真正造成混乱的，是换了规则却没有告诉读者。

这篇文章不要求你先记公式。我会先待在一个简化但自洽的Neyman–Pearson决策世界里，把下面这些问题连成一条线：

- 为什么假设检验看的是标准误，而不是标准差？
- α为什么决定临界值，却不等于“原假设为真的概率”？
- 为什么不先指定一个具体的备择假设，就没法谈β和power？
- 为什么样本量增加会提高power、降低MDE？
- “接受原假设”究竟什么时候可以说，什么时候只能说“无法拒绝”？

## 一、先把两套规则分开：证据判断，还是长期决策

很多误解都可以从这里解释。

在Fisher的显著性检验里，核心问题是：**如果原假设H₀为真，像眼前这么极端、甚至更极端的数据有多罕见**？p值是一种针对H₀的证据度量。这个框架不要求预先指定一个具体H₁，也不负责在H₀与H₁之间做对称决策。因此，数据不够极端时，严谨的说法是“无法拒绝H₀”，而不是“证明了H₀”。

在Neyman–Pearson的假设检验里，核心问题不同：**给定H₀、一个特定H₁和一条事先确定的决策规则，长期重复做决策时，两种错误各会发生多少**？这里会显式定义α、β、power和临界区域。

所以，“能不能接受原假设”不是一句脱离框架就能回答的话：

- 在只有H₀与一个特定H₁、并且必须二选一采取行动的决策设置中，可以说“接受H₀”。这里的“接受”只表示按H₀采取行动，不表示已经证明H₀为真。
- 在只用p值衡量反对H₀的证据，或者现实里存在大量未建模的其他可能性时，应该说“无法拒绝H₀”。

这就像篮球和足球都可以有“手球”规则，但你必须先说自己在哪个球场。真正不一致的，不是选择其中一种语言，而是一边使用H₁、β、power和MDE，一边又假装自己从未进入两假设的决策框架。

下面为了把关系讲清楚，我们先使用一个单侧、固定样本量、只有H₀和一个特定H₁的简化模型。最后再把边界补回来。

## 二、假设检验为什么用标准误，而不是标准差

假设我们在做一个A/B测试，关心处理组与对照组的均值差：

δ = μ_T − μ_C

原假设是没有处理效应：

H₀: δ = 0

我们真正拿到的不是总体里的δ，而是从有限样本算出的估计值δ̂。即使H₀真的成立，重复抽样得到的δ̂也不会每次恰好等于0，而会在0附近波动。假设检验要建模的，正是这个**估计量的抽样分布**。

这里必须分清两个概念：

- **标准差（standard deviation）**：描述观测值本身有多分散。
- **标准误（standard error）**：描述估计量在重复抽样中有多分散，也就是我们的估计有多不稳定。

在视频的简化示例里，基础分布的标准差固定为σ=1，样本量是n=30，于是：

SE = σ / √n = 1 / √30 ≈ 0.18

真实的两组独立A/B测试里，均值差的标准误更接近：

SE(δ̂) = √(σ_T²/n_T + σ_C²/n_C)

这条公式把实验设计里几件最重要的事连起来了：组内波动越大，估计越不稳定；分到两组的样本越多，估计越精确；分流越不均衡，在总流量相同时通常越浪费统计信息。

一个常见误解是：“数据本身很分散，所以实验一定不准。”更准确的说法是：数据的标准差会进入标准误，但最终决定估计精度的，是方差、样本量、分流方式以及估计方法共同形成的标准误。

还有一个值得补充的技术边界：视频里用n=30帮助建立直觉，但“30个样本就一定足够正态”不是中心极限定理的通用保证。近似得好不好，还取决于原分布的偏度、厚尾、相关性和所用统计量。30是教学中的经验数，不是定理给出的魔法阈值。

## 三、α不是“H₀为真的概率”，而是决策规则的错误率

有了H₀下δ̂的抽样分布，我们仍然不能做到永远正确。概率分布的尾部永远可能出现极端值：即使真实效应是0，也可能抽到一个看起来很大的正向差异。

所以我们需要先定一条决策规则。对于视频中的单侧检验：

- 如果δ̂高于临界值c，拒绝H₀；
- 如果δ̂不高于c，接受H₀——在这个简化的二选一决策世界中，也就是按“没有效应”采取行动。

如果H₀其实为真，我们却因为样本落入临界区域而拒绝它，就犯了第一类错误。α定义的是：

α = P(拒绝H₀ | H₀为真)

在示例里，H₀下的均值是0，标准误约为0.18。我们愿意让第一类错误长期发生5%，也就是α=0.05。单侧正态检验的临界点大约是：

c = 1.645 × 0.18 ≈ 0.30

于是，观察到的均值差高于0.30时拒绝H₀。蓝色尾部的面积正好约为5%。

这也说明了α最常见的几种误读：

- α不是“这次结论有5%的概率错了”；
- α不是“H₀为真的概率”；
- α不是“结果由随机性造成的概率”；
- α也不告诉你效应有多大、是否值得上线。

α是**在H₀为真的反事实世界里，这条决策规则长期误报的概率**。它描述的是程序的行为，不是对某一次假设真假的后验判断。

## 四、β为什么一定属于某个特定的备择假设

只画出H₀时，我们只能定义第一类错误。要定义第二类错误，必须先说清楚：如果H₀不成立，真实效应究竟是多少？

这一步很容易被教材略过。事实上，相对于H₀: δ=0，备择的效应大小可以是0.1、0.2、0.5、1.0……从建模上看有无限多个候选值。频率学派不会在没有额外先验的情况下给这些假设分配“为真的概率”；我们只是为了计算检验在某个反事实世界里的表现，暂时指定一个H₁。

视频先选了：

H₁: δ = 0.5

并保持标准误约为0.18、临界值为0.30。如果真实效应就是0.5，但样本估计仍落在0.30左侧，我们没有拒绝H₀，也就漏掉了一个真实效应。这是第二类错误：

β = P(没有拒绝H₀ | 这个特定H₁为真)

在当前二选一规则里，它也等价于“这个特定H₁为真时，却拒绝了H₁”。

这里最重要的不是记住β的句子，而是看懂它依赖什么：

1. **H₁的效应大小**：H₁离0越远，越容易和H₀区分，β越小。
2. **标准误**：分布越窄，两个世界重叠越少，β越小。
3. **临界值**：在其他条件不变时，阈值向右移动会降低α，却增加β。

所以，脱离效应大小问“这个实验的power是多少”，信息是不完整的。同一个实验，对5%的lift可能很有power，对0.5%的lift却可能几乎没有power。Power不是实验脱离H₁后自带的一个固定属性。

这也是为什么“α和β是一对固定的对称数字”是错的。给定H₀、H₁、样本量、方差和检验规则之后，二者才被共同确定；改变任何一个条件，β都可能改变。

## 五、Power=1−β，但为什么这叫“功效”

教科书写下Power = 1 − β之后，很多解释就结束了。真正需要理解的是：这个面积为什么对应我们想要的能力。

可以从三个层次看。

第一，从图上看，β是H₁分布落在“不拒绝H₀”区域的面积；剩下落在“拒绝H₀”区域的面积就是1−β。因此：

Power = P(拒绝H₀ | 特定H₁为真)

第二，从行动上看，power就是**真实效应存在时，检验成功把它识别出来的概率**。如果power是80%，并不是说结论“80%可信”，而是说：假设真实效应正好等于我们设计时指定的那个值，长期重复同样的实验，大约80%会越过决策阈值，约20%仍会漏掉。

第三，从机制上看，样本量增加为什么会提高power：

样本量增加 → 标准误下降 → 抽样分布变窄 → 在固定α下临界值更靠近0 → H₁落在拒绝域的面积增加 → β下降、power上升

在视频的例子里，样本量从30增到100，标准误从约0.18降到0.10。在仍保持α=5%时，临界值从约0.30降到0.16。对于同一个H₁: δ=0.5，两个分布的重叠大幅减少，power从约86%变得接近100%。

注意：更多样本没有让真实效应变大。它只是缩小了我们对效应估计的不确定性，让同一个效应更容易跨过阈值。

## 六、MDE不是“最小存在的效应”，而是实验设计的灵敏度

现在可以解决前面留下的问题：世界上明明有无限多个备择效应，我们为什么在power calculation里只谈一个？

因为我们不是在声称某个H₁比其他H₁更“真实”，而是在寻找一条**设计边界**。

给定：

- H₀与检验方向；
- 可容忍的α；
- 目标power，也就是可容忍的β；
- 样本量与分流；
- 指标方差及估计方法；

MDE（minimum detectable effect，最小可检测效应）就是：**使检验达到目标power的最小真实效应大小**。比它更大的效应通常会有更高power；比它更小的效应则低于设计目标。

在视频的单侧正态示例里，α=5%、目标power=80%，也就是β=20%。这时可以把关系写成：

MDE ≈ [z(1−α) + z(1−β)] × SE

由于z(0.95)≈1.645，z(0.80)≈0.842：

MDE ≈ (1.645 + 0.842) × 0.18 ≈ 0.45

这正是图里的0.45。如果实际效应是0.50，power约为86%；如果效应正好是0.45，power约为80%。

当样本量从30增加到100，标准误从约0.18降到0.10；保持α和β不变：

MDE ≈ (1.645 + 0.842) × 0.10 ≈ 0.25

于是得到整期内容最重要的关系之一：

样本量增加 → 标准误下降 → 在相同错误容忍度下，MDE下降

也就是说，更多样本让你有能力稳定识别更小的效应；反过来，如果产品改动真的能产生很大的效应，即使公司流量没有那么大，A/B测试仍然可能可靠地检出它。

但MDE也经常被误解。它不是：

- 世界上可能存在的最小效应；
- 小于它就一定不显著的硬阈值；
- 实验预期一定会带来的lift；
- 业务上值得上线的最小价值；
- 达到它就保证被发现的承诺。

一个真实效应正好等于MDE、目标power为80%的实验，本来就仍有20%的概率漏掉它。小于MDE的效应也可能因为抽样波动偶然显著，只是长期检出概率没有达到设计标准。MDE描述的是检验程序的灵敏度，不是现实效应的存在边界。

实际双侧A/B测试会把z(1−α)换成z(1−α/2)，两组方差、分流比例、聚类或时间相关性也会改变标准误；但整条机制不变。

## 七、真正的权衡不是“α对β”，而是错误容忍度对发现能力

现在把所有概念放回一张图里：

方差、样本量、分流与估计方法 → 标准误

H₀下的抽样分布 + α → 临界值

特定H₁ + 标准误 + 临界值 → β

Power = 1 − β

给定α与目标power，反推能达到要求的最小H₁ → MDE

在样本量、方差、H₀和H₁都不变时，移动临界值确实会在α与β之间做交换：阈值更严格，误报更少，但漏报更多；阈值更宽松，发现更多，但误报也更多。

但实验设计真正要解决的，不是机械地让两个数字都尽可能小。那通常做不到。真正的问题是：**我们愿意承担怎样的错误，换取发现多小效应的能力？**

增加样本量或降低方差，可以把整条边界向外推，让α和β不必只做零和交换。这就是很多实验技术最终都能用power解释的原因：

- **CUPED等方差缩减方法**：如果使用处理前、且能预测目标指标的协变量降低残差方差，就能减小标准误，在相同流量下提高power。
- **样本量与实验时长**：更多流量通常意味着更小标准误，但也意味着更长等待或更多实验资源占用。
- **序贯检验**：如果你想边看结果边决定是否停止，不能继续假装自己在做普通固定样本检验；有效的序贯方法会重新设计决策边界，继续控制错误率。
- **低power实验**：首先意味着更容易漏掉真实效应。若再叠加反复偷看、多指标筛选或只汇报显著结果，最终看到的“发现”也会变得很不可靠。
- **统计显著与业务显著**：一个非常小的效应可以在海量样本下显著，却未必值得上线。设计MDE时，最好让它和“最小值得行动的效应”发生关系，而不是只接受计算器的默认值。

因此，实验速度、可用流量、指标噪声与希望检出的效应大小，始终是一组联动选择。公司没有巨大样本量，不代表不能做A/B测试；它意味着你必须诚实面对：在当前噪声和流量下，自己究竟有能力发现多大的变化。

## 最后，用五句话检查自己是否真的理解了

1. 假设检验判断的是估计量，所以核心不确定性是标准误，不是观测值本身的标准差。
2. α是H₀为真时拒绝H₀的长期概率，不是H₀为真的概率。
3. β和power都对应一个特定效应大小；不指定H₁，就不能完整定义它们。
4. 更多样本不会放大效应，只会缩小标准误；因此power上升、MDE下降。
5. MDE是实验设计在指定α与power下的灵敏度，不是现实里效应是否存在的分界线。

如果你能从标准误一路推到临界值、β、power和MDE，而不需要分别背十个定义，你才真正理解了假设检验。
