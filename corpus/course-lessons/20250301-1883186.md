# 第04课｜警惕固定思维：你的人生本该如此吗？

## **第四课：从固定到成长——解锁你的人生潜力引擎**

**为什么成长型思维是成功的底层代码？**

嘿，同学们好！欢迎回到我们的“从会工作到会赚钱”系列课程。上一节课，咱们聊了从“客体思维”到“主体思维”的转变，希望能给大家的思维方式来一次“源动力”升级。那这节课，咱们就来点实在的，讲讲具体怎么做。

要说最有用的方法，那必须是从 **固定型思维 (Fixed Mindset)** 转变为 **成长型思维 (Growth Mindset)**。

说起来，成长型思维几乎是我个人频道奠基性的内容。四年前我发过一期专门讲它的视频，后来我自己也反复看过很多遍。很多观众朋友后来跟我反馈，那期视频真的在很深的层面上改变了他们的人生轨迹。不信你去翻翻B站和油管的评论区，好多人说看过之后，过了两年还会回来看，每次都有新收获。

你看，在我们会员社区里，大家做自我介绍时，搜一下“成长型思维”这个关键词，就会发现很多人都在提。一旦了解了这个思维方式，大家都会下意识地提醒自己：要做一个拥有成长型思维的人。

因为它，实在是太！有！用！了！

**成长型思维：为什么它如此重要？**

我觉得它厉害的地方主要有两点：

1. **解释力超强**：很多所谓的成功要素，其实都有些“可有可无”。你说勤奋吧，总有些大佬好像躺着也能成功；你说天赋吧，更多成功人士恰恰是靠后天努力拼出来的。但“成长型思维”非常独特，你几乎能在**所有**成功人士身上找到这个特质。很难找到一个顶尖人物是抱着固定型思维成功的。所以，它是成功的一个非常、非常必要的条件。
2. **简单易学，立竿见影**：这玩意儿很神奇，它不像练肌肉需要日积月累。有时候，十分钟的思维转变就够了。你上完这节课，知道了什么是成长型思维，就能在接下来的生活中随时随地去运用它。我之前总结过32个成功要素，但如果让我只挑一个来讲，我绝对优先讲“成长型思维”。

**小测试：你是哪种思维模式？**

来，咱们先做个小测试，看看你更偏向哪种思维？

**问题：你觉得智力可以改变吗？**

A. 我可以学会新东西，但我的聪明程度（智力）基本上是天生的，很难改变了。

B. 很大程度上，我的智力是可以被提升和改变的。

欢迎把你的答案打在公屏上或者留在评论区！

其实啊，我们每个人都是混合体 (mixed mindset)，在某些方面是成长型，在另一些方面是固定型，大多数时候是两者交织。但对于“智力能否改变”这个根本问题的看法，很大程度上决定了你的思维底色。

- 如果你选 **B**，认为能力（包括智力）都是可以培养的，那你的思维基础就是 **成长型** 的。
- 如果你选 **A**，认为能力是静态的、天注定的，那你的思维基础就是 **固定型** 的。

所以，想拥有成长型思维，第一步就是要从根本上相信：**能力，是可以被改变的！**

**为什么能力可以被改变？—— 回归“手艺”的本质**

还记得我们第二课讲的吗？工作和赚钱的本质，很多时候就像是学一门“手艺”。我们在学校里习惯了考试，容易把“能力”和分数、排名这些静态的东西挂钩。但生活中的学习完全是另一回事。

你想想：

- 你能只通过看视频就学会滑雪吗？不行，得摔跤，得练习。
- 你能只通过看视频就学会转笔吗？（看，我现在还在笨拙地练习，转得不好，但我相信练下去就能学会！）

转笔这个小技能，最后呈现的是一个结果。如果你只看到我最终学会后的视频，可能会觉得“哇，你好厉害！” 但实际上，我转得好不好，完全取决于我投入了多少练习，克服了多少笨拙。

如果这个例子还不够，我强烈推荐大家看一本书叫《刻意练习》。书里甚至提到，连我们通常认为纯靠天赋的“绝对音准”(perfect pitch)，其实也是可以通过刻意练习后天获得的！研究发现，经过正确的训练，几乎所有人都能掌握它。

所以，我们生活中遇到的大多数事情，本质上都是“手艺活”。关键在于：你有没有兴趣学？你想不想学？你愿意为它投入多少努力、克服多少困难？只要这三点到位，绝大多数能力，都是可以被培养出来的。

**这，就是成长型思维的核心信念。**

**固定型 vs 成长型：两种思维，两种人生**

这两种思维模式，会像两条岔路，引导我们做出截然不同的选择，抓住完全不同的机会。我们来对比一下：

**方面固定型思维 (Fixed Mindset)成长型思维 (Growth Mindset)对能力的看法**我不擅长的东西，就是学不好。能力是天生的。只要努力，我什么都能学。能力是可以培养的。**面对新机会**“我不行”，倾向于拒绝，害怕暴露“短板”，即使接受也充满内耗。“太好了，新挑战！”，心态开放，直接开干，较少内耗。**做事的动力为了证明**：证明自己天生就聪明、有能力。**为了提升**：在过程中学习、进步、提高自己。**对待挑战避免挑战**：挑战意味着可能失败，失败=我不行。**寻求挑战**：挑战是成长的机会，失败是学习的过程。**对待失败失败是否定**：失败证明了我能力不足，是灾难。**失败是信息**：失败告诉我哪里需要改进，是宝贵的反馈。**对待反馈视为批评/否定**：“你说我这儿要改，就是觉得我不行？”**视为礼物/帮助**：“谢谢你帮我看到盲点，我又可以进步了！”**看待自己成功**因为我天生聪明/有天赋。因为我付出了努力，克服了困难。**看待他人成功威胁**：别人比我成功，显得我“不行”，资源被抢走了。**激励/榜样**：看到可能性，也看到别人付出的努力，激励自己去行动。

你看，拥有成长型思维的人，就像一个不断升级打怪的玩家，每次挑战都能让他变得更强。而固定型思维的人，则像一个守着初始装备，生怕掉血的玩家，总想待在安全区，最终可能连原有的水平都发挥不出来。随着时间推移，两者的差距会越拉越大。

咱们中文里也有对应的说法：

- “江山易改，本性难移” —— 这就是典型的固定型思维，听着就让人泄气，像是某种文化糟粕，咱别信这个。
- “故天将降大任于是人也，必先苦其心志，劳其筋骨……所以动心忍性，曾益其所不能。” —— 孟子这话，就是标准的成长型思维，是咱们文化的精华，得刻在心上！

**深化理解：压力是你的朋友？**

之前推荐过卡罗尔·德韦克的《终身成长》(Mindset) 这本书，也就是“成长型思维”这个概念提出者的著作。不过说实话，那本书第一章就把核心讲透了，后面很多例子可能离我们有点远。

我反而更推荐大家去看看神经科学大佬 Andrew Huberman 的两期播客/视频：

1. 一期是他深入讲解成长型思维，以及如何获得它。
2. 另一期是他访谈斯坦福大学的 David Yeager 教授。Yeager 教授做了一个非常厉害的研究，主题是 **“压力提升表现”心态 (Stress is Performance Enhancing Mindset)**。

Yeager 教授和他的团队跑到很多学校去做实验。他们给一部分学生看一些非常简单的材料，告诉他们：你感受到的压力，其实是可以帮助你提高表现的。另一部分学生则不看。长期追踪下来发现，那些接触了“压力能提升表现”信息的学生，应对压力的能力更强，长期的学业表现也更好！

这个“压力提升表现”的心态，和成长型思维简直是天作之合！你想啊，成长的机会往往伴随着挑战，挑战自然带来压力 (stress)。如果你能相信并利用这种压力来提升自己（而不是被它压垮），你就形成了一个完美的正循环：**挑战 → 压力 → 积极应对/利用压力 → 表现提升/能力增长 → 更渴望挑战**。这样，你就能从压力中获得更多激励，而非挫败感。

**实战演练：新项目来了，你和小S的选择？**

好了，理论讲得差不多了，上案例！假设你的同事 **小S 是成长型思维**，而 **你是固定型思维**。

**场景：** 你们组里来了个新项目。这个项目：

- 挑战不小，风险挺大。
- 有很多目前不知道怎么解决的问题。
- 领导挺关注。
- 项目组里已经有几位资深同事了。

**固定型思维的你，可能会这样想：**

- **挑战大 = 风险高：** “这么多难题，我肯定搞不定。我现在不会，以后也学不会。”
- **领导关注 = 压力山大 + 失败风险高：** “领导盯着呢，万一搞砸了多丢人？领导那么上心，肯定不能容忍失败。”
- **有资深同事 = 功劳被抢，黑锅我背：** “做好了，功劳肯定是他们的，说是我被带着飞；做差了，他们肯定把锅甩给我这新人。里外不是人啊！”
- **结论：** “这项目绝对不能接！坑太多了！”

**而成长型思维的小S，则会这样想：**

- **挑战大 = 学习机会多：** “太棒了！这么多难题，正好能逼我学会现在不会的东西，技能点又能加满了！”
- **有资深同事 = 宝贵资源：** “太好了！可以向大佬们请教，跟他们合作，肯定能学到超多东西！”
- **领导关注 = 项目重要性高 + 资源保障：** “领导重视，说明这事儿有价值，不会半途而废。就算遇到困难，领导也会协调资源来支持，这事能成！”
- **风险 = 正常现象 + 成就感来源：** “新项目没风险才不正常呢。要是板上钉钉谁都能做，那还有啥意思？克服困难做成了才有成就感嘛！”
- **结论：** “这项目简直是为我量身定做的机会！接！”

**后续发展呢？**

假设最后你还是不情不愿地接了。项目推进中遇到问题：

- **你 (固定型)：** 内心慌得一批：“完了完了，果然不行！” 第一反应是想办法掩盖问题，或者把责任推出去。跟领导汇报时，也倾向于报喜不报忧，或者撇清自己。
- **小S (成长型)：** 心态稳健：“新项目遇到问题太正常了。” 第一反应是：1. 我自己能不能解决？ 2. 能不能请教同事一起搞定？ 3. 如果实在不行，需要哪些额外资源或领导指示？ 然后，如实地把问题和进展反馈给领导，一起商量对策。

现在，**你站在领导的角度想一想**：在这个关键项目上，你更希望看到谁的表现？是一个遇到问题就掩盖、甩锅、不主动推进的人？还是一个直面问题、主动寻求解决方案、并坦诚沟通的人？

**答案不言而喻，肯定是小S。**

所以你看，无论是争取机会，还是获得信任和重用，成长型思维都完胜。

**成长型思维的好处：不止于工作**

到这里，我希望我已经充分证明了：固定型思维，百害而无一利；而成长型思维，无论在什么环境下，都能让你受益匪浅。

总结一下成长型思维能带给你的：

- **持续成长，能力提升**：你的技能树不断点亮。
- **更多选择，更好机会**：能力强了，选择自然多，能抓住更有价值的机会。无论是内部晋升还是跳槽去更好的平台，都需要能力做支撑。
- **更强韧性，不怕挑战**：把困难看作成长阶梯，心态更稳。
- **更好的人际关系**：乐于接受反馈（来自领导、同事），真心为他人成功喝彩（视作激励而非威胁），这种积极的潜意识别人是能感受到的。
- **更深的内在快乐和掌控感**：快乐源于“成长”本身，而不是不确定的“结果”。这恰恰是上节课讲的“主体思维”的体现——专注于自己可控的部分（努力和成长），并为自己的选择负责。成长，是最可控的事情之一！

（悄悄预告一下，下一课我们会讲“打分思维”的问题，这会帮你更深刻地理解为什么追求“能力成长”本身，比追求“分数成长”更可靠、更可控。）

**三句“咒语”，助你修炼成长型思维**

最后，送给大家三句话，你可以当作“咒语”或者提醒，写下来贴在显眼的地方，或者时常在心里默念，帮助自己内化成长型思维：

1. **关注自己的“付出”，而非“表现”——尤其是在你做得好的时候！**
  - 当你取得成绩时（比如学一项新技能、获得晋升），尤其要回顾自己为此付出了多少努力。这会强化大脑中“付出带来好结果”的连接，让你的大脑奖励“努力”本身，从而在潜意识里更倾向于付出。这对于长期塑造 成长型思维至关重要。

2. **遇到挑战时，问自己：“我能从中学到什么？”**
  - 我们（尤其是从小被“绩优主义” PUA 大的人）很容易在遇到挫折时陷入无尽的内耗和灾难性联想（“这次考不好 → 绩点低 → 找不到好工作 → 人生完蛋了”）。打住！别想那些没用的，就问自己这一句：“我能学到什么？” 把注意力拉回到成长上。

3. **提醒自己：“科学证明，适度的压力能提升表现。”**
  - 每当你感到压力时，记住，这个压力本身就可以成为你的助力。这句话能帮你调整心态，化压力为动力。当然，如果压力过大，超出了承受范围，还是要及时寻求帮助，别硬扛。但在适度压力下，这句话就是你的强心剂。

**课后练习：用新视角看旧伤疤**

好了，理论和工具都给你了，实践一下吧！

**作业：** 回顾一次你印象比较深刻的失败或挫折经历。尝试用我们今天讲的 **成长型思维**，重新解读那次经历。

- 当时你关注了什么？（表现？结果？别人的看法？）
- 如果用成长型思维，你会关注什么？（付出的努力？学到的教训？可以改进的地方？）
- 那次经历中，有哪些可以学习和成长的点，是你当时忽略的？
- 重新解读后，你对那次“失败”的感受有什么不同？

欢迎大家认真思考，把你的答案或者感悟留在评论区。这个练习对于内化成长型思维，把它真正运用到你的工作和生活中，非常有帮助。
