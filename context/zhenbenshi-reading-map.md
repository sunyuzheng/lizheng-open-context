# 《真本事：从会工作到会赚钱》阅读地图

《真本事》讨论一个从学校进入真实世界以后经常被遮住的问题：会完成组织里的工作，不自动等于拥有能被市场持续选择的能力；收入、职业选择与自由，也不能只靠更努力地完成别人给出的记分牌。

这份文件用于快速检索、理解和找到原书位置。更完整的可开发内容见[《真本事》完整框架参考 V1](zhenbenshi-frameworks.md)：它来自作者自有的课程与书籍框架，并由作者明确开放。仓库不复制出版社版式、插图或第三方授权素材，也不提供投资与职业结果保证。

## 七套核心框架

### 1. 三种思维升级

- **客体 → 主体**：承认外部不公与真实限制，同时继续寻找仍能选择、影响、记录、协商、求助或退出的部分。它不能用来把结构性伤害归咎于个人。
- **固定 → 成长**：检查一项能力是否能通过练习、反馈或换环境提高，也同时评估时间、成本、机会窗口与任务适配。
- **打分 → 多维**：分数、职级、薪资与排名会压缩复杂现实。先问这个单一指标遗漏了什么，再为当前决定选择少数重要维度。

### 2. 手艺思维

把重要能力看作一门需要在具体问题中持续打磨的手艺：结果可以观察，研究越深越能看见新维度，而且无法只靠读书学会。

书中的 `行动 : 思考 : 求知 = 6 : 3 : 1` 是提醒人不要只输入不实践的启发式，不是固定配比。危险任务、探索期、基础不足或反馈昂贵时，比例可以不同。

### 3. 财务自由公式

书中用“被动收入覆盖支出”作简化定义，并用时间、支出、收入与收益率检查长期路径。现实还要加入税、通胀、波动、债务、家庭责任、保险、流动性与风险承受能力。

这是一套思考变量的方法，不是投资建议。尤其要警惕认知错配、FOMO 与情绪驱动。

### 4. 个人价值公式

> **了解市场 × 打造产品 × 利用杠杆**

乘号表示三个维度互相制约，不是可计算等式，也不定义人的价值。

- **了解市场**：当问题是商业交换时，人们愿意为什么结果付费？努力、技能难度、公共价值与市场价格不是同一件事。
- **打造产品**：把真实客户、最小可评估版本、投放反馈与迭代连接起来。表达经历时区分投入、产出与成果。
- **利用杠杆**：寻找投入差异能显著改变结果的场景，使用公司、内容、代码、品牌、关系、趋势与 AI 等杠杆，同时检查目标是否一致、风险由谁承担。

### 5. 道、天、地、将、法

职业判断不能只看执行技能：

| 层 | 检查什么 |
|---|---|
| 道 | 你如何理解问题与判断机会 |
| 天 | 行业、周期与时代变化 |
| 地 | 公司平台、业务位置与资源 |
| 将 | 领导和关键同事带来的标准、支持与风险 |
| 法 | 方法、技能与执行是否解决当前瓶颈 |

这个框架提醒人看见层级，不给所有人规定同一个排序。

### 6. 找到少数高价值工作

`10%` 是强调价值差异的启发式，不是固定分布。可以追问：把它做好会带来什么成果？不做最坏会怎样？它只是占满时间，还是让人与结果更近？

减少低价值工作需要考虑职责、团队公平、关系与风险；不能把所有维护、协调或支持工作都简单判成无效。

### 7. 手艺、坚持与长期选择权

书中的 `成功 ≈ 手艺 + 坚持` 强调长期实践，没有把资源、健康、时机、关系、结构与运气全部写进公式。更完整的用法是：找到愿意长期打磨、也能遇到真实需求的能力；持续检查它能否在当前平台之外仍然成立；让高质量且可见的工作增加机会出现的概率。

## 21 章定位

1. 从“好学生 → 好工作 → 赚大钱”的梦中醒来
2. 学习的正确方法——告别校园思维，拥抱真实世界
3. 警惕客体思维，学会对自己负责
4. 警惕固定型思维——解锁成功的底层代码，释放人生潜力
5. 警惕打分思维——接纳世界的多样和复杂
6. 重塑思维模式，开启你的财务自由之路
7. 通往财务自由之路——重塑你的财富观
8. 投资的陷阱：金钱、时间和人生的无底洞
9. 个人价值公式——从会工作到会赚钱的核心
10. 从理想到行动——实现个人价值的具体路径
11. 选择的智慧：用“道、天、地、将、法”规划职业发展
12. 抓住工作中 10% 的核心价值
13. 洞悉商业本质：实现增长的核心法则
14. 跨过阻碍，了解真正的市场
15. 产品打造方法论：以简历为例
16. 利用杠杆：放大影响力与加速成长
17. 职场中的“元能力”——沟通
18. 投资：少踩坑、建体系，理解市场并穿越喧嚣
19. 赚钱：一项需要磨炼的技能
20. 告别空想：将赚钱意愿转化为行动
21. 找到属于你的“长坡厚雪”：坚持与自我认知

## 常见问题怎样进入这本书

| 问题 | 先读的框架 / 章节 |
|---|---|
| 如何找适合写进简历的项目 | 个人价值公式；第 14–16 章，尤其第 15 章 |
| 如何复盘一个项目 | 手艺思维；投入—产出—成果；真实反馈 |
| 要不要跳槽或换行业 | 道天地将法；第 11 章 |
| 工作很多但成长很慢 | 少数高价值工作；第 12 章 |
| 如何升职、加薪或做副业 | 了解市场 × 打造产品 × 利用杠杆 |
| 怎样开始财务规划 | 财务自由变量与投资陷阱；第 6–8、18 章 |
| 我是不是不适合某项能力 | 固定/成长透镜，同时检查成本与适配 |
